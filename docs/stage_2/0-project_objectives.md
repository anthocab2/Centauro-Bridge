# Define Project Objectives

## Project purpose

Centauro Bridge helps students and data researchers collect, check, and explore
daily market data through a local application. It connects Massive to MongoDB
Atlas, tracks each extraction, and displays verified results in a table and
chart. The MVP aims to reduce manual work, make data exploration easier, and
give users a clear distinction between a requested job and a verified result.

## SMART objectives

The following targets use the four-week plan in the
[Project Charter](./PROJECT_CHARTER.md). Week 1 begins on the start date agreed
by the project owner and academic reviewer; no course deadline has been assumed.

1. **By the end of Week 2**, complete two daily-data extractions for two distinct
   supported ticker symbols, each covering no more than five trading days.
   Both must finish with verified results stored in the MVP database, with data
   present in at least one. Record each request, final status, and verification
   outcome.
2. **By the end of Week 3**, have two volunteer users each open a verified
   extraction and apply a date filter using the written guide, without live
   assistance, within ten minutes after setup. Verify that each table and chart
   shows the same filtered records, and record completion time and difficulties.
3. **By the end of Week 4**, pass four documented scenarios: reject a simultaneous
   request as busy, resume an interrupted job, reuse a completed request without
   duplicate stored records, and block viewing of altered or incomplete data.
   Deliver the guide, results, and demonstration with no unresolved defect that
   prevents these scenarios or the first two objectives.

These are proposed targets for the existing MVP, not results already achieved.
Real service access and volunteer availability are prerequisites. The project
owner and reviewers still need to confirm the plan together.
